# JARVIS — офлайн-ассистент для Windows

Интерфейс программы на украинском. Голосовые команды распознаются локально на русском или английском; язык выбирается в «Налаштування». Камера показывает зеркальное изображение. Управление компьютером рукой включается отдельно в «Камера» и при каждом запуске должно быть включено вручную.

## Запуск из исходного кода

Откройте папку проекта в **PowerShell** и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_models.py
.\.venv\Scripts\python.exe main.py
```

Если `py` не видит Python, найдите установленный `python.exe` и выполните `<путь-к-python.exe> -m venv .venv`.

В Git Bash используйте `./.venv/Scripts/python.exe main.py`. Обратные слеши Windows, написанные как команда Bash, не работают. Если папка моделей уже готова, установка её пропустит. Модели скачиваются один раз; распознавание работает локально. При запуске ассистент не должен сам запускать камеру или управление жестами.

## Команды

Примеры: «Джарвис, открой браузер», «Джарвис, который час», «Джарвис, выключи компьютер». Английский вариант — «Jarvis, open browser». Последняя фраза выключает Windows сразу, без дополнительного диалога; сохраните работу перед её произнесением. Кнопка выключения в интерфейсе имеет отдельное подтверждение.

В «Команди» можно сохранить несколько фраз для одного действия и выбрать язык, файл `.exe` или сайт `https://`. Настройки и команды хранятся в `%APPDATA%\JARVIS`. При переносе старого `commands.json` создаётся резервная копия. Для проверки микрофона используйте кнопку проверки команд: она отображает распознанный текст без исполнения действия.

## Жесты

Откройте «Камера», включите отслеживание и отдельно разрешите управление. Указательный палец двигает курсор. Сведение большого и указательного пальцев — левый клик; большого и среднего — правый клик. Два поднятых пальца — прокрутка; большой палец вверх/вниз — громкость. Нажатие Esc отключает управление даже когда окно JARVIS находится на фоне. При потере руки новый клик требует снова показать нейтральную ладонь. Качество зависит от освещения, расстояния до камеры и скорости движения руки.

## Сборка

После установки библиотек и моделей выполните `build_exe.bat`. Результат — `dist\JARVIS\JARVIS.exe`. Переносите **всю** папку `dist\JARVIS`: ей нужны соседние `_internal` и `models`.

Проверка исходников: `.\.venv\Scripts\python.exe -m pytest -q`. Автоматические тесты используют подставную камеру и микрофон и не выполняют щелчки, запуск программ или выключение ПК. Физические устройства и распознавание вашей речи проверьте вручную.

## Как устроена программа

- `main.py` создаёт приложение Qt и главное окно.
- `jarvis_ui/` строит страницы, рисует центральное ядро и показывает состояния. `window.py` связывает кнопки и рабочие модули.
- `jarvis_voice/` получает звук с микрофона, выводит его уровень и распознаёт фразы моделью Vosk. Рабочий поток не блокирует окно.
- `jarvis_commands/` проверяет ключевое слово, сопоставляет фразы с действиями, сохраняет собственные команды и вызывает Windows-действия.
- `jarvis_camera/` читает кадры камеры в отдельном потоке, зеркалит их и передаёт интерфейсу только последний кадр.
- `jarvis_gestures/` находит 21 точку руки, определяет жесты и при явном разрешении отправляет мышиные команды Windows. Обработка кадра идёт в потоке камеры.
- `jarvis_settings/` сохраняет настройки; `resources/languages/` содержит отдельные словари RU/EN; `models/` содержит локальные модели.
- `tests/` проверяет переходы состояния, команды, безопасность жестов и работу интерфейса без физических устройств.
- `setup_models.py` скачивает проверяемые файлы моделей; `build_exe.py` упаковывает приложение и ресурсы.

Путь команды: микрофон → Vosk → проверка «Джарвис» → словарь выбранного языка → действие → журнал и состояние ядра. Путь жеста: камера → точки руки → фильтр устойчивости → Windows-ввод → зеркальное видео в окне.
