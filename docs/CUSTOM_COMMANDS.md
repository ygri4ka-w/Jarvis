# Власні команди та вимкнення ПК

У вкладці «Голос» натисніть **«Додати команду»**:

1. Введіть фразу російською без звернення, наприклад `открой игру`.
2. Натисніть «Обрати файл» і виберіть потрібну програму `.exe`.
3. Натисніть «Зберегти» й дочекайтеся перевірки слів у Vosk.
4. Під час роботи асистента скажіть: **«Джарвис, открой игру»**.

Нова команда доступна без перезапуску. У «Мої команди» можна змінити фразу
або шлях, видалити команду та перевірити запуск кнопкою. «Перевірити запуск»
реально відкриває вибрану програму й працює без увімкненого мікрофона.
Програма запускається зі своєї папки; додаткові аргументи командного рядка
в цьому етапі не налаштовуються.

Якщо слова немає у словнику Vosk, змініть фразу на звичайні російські слова.
Наприклад, замість назви продукту використайте «открой игру». Можна свідомо
зберегти попри попередження для ручного запуску, але додавання фрази не
додає нові слова в саму модель. Якщо модель відсутня, перевірка повідомить
про це; установіть її через `setup_voice_model.py`.

Налаштування зберігаються в `%APPDATA%\JARVIS\commands.json`.
Вони зберігаються після перезапуску програми та оновлення коду. Вбудовані
фрази зарезервовано, дублі фраз не дозволяються. Якщо файл налаштувань
пошкоджений, він не перезаписується: виправте або перейменуйте його та
перезапустіть програму. Якщо `.exe` переміщено, змініть шлях у команді.

## Вимкнення комп’ютера

Під час роботи асистента скажіть **«Джарвис, выключи компьютер»** — запит
на вимкнення надсилається одразу, без додаткового вікна підтвердження.
Звернення «Джарвис» обов’язкове. Збережіть документи до голосової команди.
Кнопка «Вимкнути ПК» зберігає вікно з кнопками «Вимкнути» та «Скасувати».
JARVIS надсилає
Windows запит на вимкнення без примусового закриття програм. Фактичне
вимкнення не виконувалося під час автоматичних тестів.

Вмикання повністю вимкненого ПК з самого JARVIS неможливе: програма в цей
момент не працює. Для Wake-on-LAN потрібен інший пристрій і підтримка
мережевої карти/BIOS. Віддалене ввімкнення поки не налаштоване.

Нові модулі: `jarvis_commands/store.py` — файл налаштувань,
`jarvis_ui/command_editor.py` та `command_manager.py` — вікна команд,
`jarvis_voice/vocabulary.py` — перевірка слів,
`jarvis_commands/power.py` — запит на вимкнення після підтвердження.
