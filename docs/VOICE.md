# Голос: Vosk, російські команди

Інтерфейс залишається українською. Голосове розпізнавання використовує
локальну російську модель `vosk-model-small-ru-0.22`. Звукова хвиля показує
реальний сигнал мікрофона, зокрема під час очікування звернення.

## Запуск

У папці проєкту:

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe setup_voice_model.py
.venv\Scripts\python.exe main.py
```

Модель установлена цим оновленням. Повторне завантаження потрібне тільки
після видалення моделі або на іншому комп'ютері. Звичайний запуск не потребує
мережі; звук не записується у файл і не надсилається на сервер.

Відкрийте «Голос», виберіть мікрофон, запустіть асистента й дочекайтеся
«Очікує «Джарвис»». Вимовляйте звернення та команду російською:

- «Джарвис, открой калькулятор»
- «Джарвис, открой блокнот»
- «Джарвис, открой браузер»
- «Джарвис, который час»
- «Джарвис, останови ассистента»

Або скажіть «Джарвис», дочекайтеся «Слухаю команду…» і почніть команду
протягом п'яти секунд. Команда виконується після завершення фрази та паузи;
проміжний текст відображається, але не запускає дій. Результати, повідомлення
про помилки й кнопки — українською. Браузер відкриває Google.

Під час роботи Vosk звук обробляється без спеціального режиму паузи Whisper.
Невідомі фрази не виконуються, однакові команди протягом двох секунд
фільтруються. Зупинка і від'єднання мікрофона скасовують запізнілі результати.
Камера та голос обробляють помилки незалежно. Дзеркальний режим камери збережено.

## Файли

- `jarvis_voice/recognition.py`: адаптер Vosk, локальна модель та часові мітки
  початку слів для коректного вікна активації.
- `jarvis_voice/audio.py`, `worker.py`: мікрофон, черга звуку, фоновий потік.
- `jarvis_voice/controller.py`: зв'язок розпізнавання з GUI та командами.
- `jarvis_ui/voice_panel.py`, `waveform.py`: український інтерфейс і хвиля.
- `jarvis_commands/router.py`: підтримувані російські фрази.
- `jarvis_commands/actions.py`: конкретні дії та українські результати.

Для нової команди додайте російську фразу в `COMMANDS`, обробник дії й тест.
Нові слова повинні бути в словнику моделі Vosk. Розпізнаний текст ніколи не
виконується як довільна команда оболонки.

## Перевірка

```bat
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m tests.vosk_smoke
```

Автотести не використовують фізичні пристрої й не відкривають програми.
Smoke-перевірка завантажує реальну російську модель, перевіряє слова всіх
команд та обробку штучної тиші. Точність на вашому голосі потрібно перевірити
після запуску. Якщо слів немає у розпізнаному тексті, перевірте вибраний
мікрофон, його рівень і дозволи Windows.

Для EXE після `build_exe.bat` скопіюйте папку `models/vosk-model-small-ru-0.22`
у `dist/models/vosk-model-small-ru-0.22`. Модель зберігається поруч із EXE.
EXE під час цього переключення не збирався.

Попередня модель Whisper на диску не видаляється, але JARVIS її більше не
завантажує. Джерело моделі: https://alphacephei.com/vosk/models
