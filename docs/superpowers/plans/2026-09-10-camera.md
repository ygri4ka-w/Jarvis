# Camera Implementation Plan

**Goal:** Integrate OpenCV webcam capture into Variant 1.
**Architecture:** Qt-free capture, QThread worker with a latest-frame mailbox,
Qt display panel, and lifecycle coordination in the existing window.
**Tech Stack:** Python 3.13, PySide6 6, OpenCV 4, pytest.
**Spec:** ../specs/2026-09-10-camera-design.md

## Constraints
Ukrainian UI, preserve existing dashboard, no recording or network streaming.
Default device 0; manual retry; close must not destroy a running QThread.

## Steps
- [ ] Add tests in tests/test_camera.py for Capture.open/read/close and
  CameraWorker.take_frame/stop with fake devices. Run pytest and confirm missing
  camera behavior fails before implementation.
- [ ] Implement jarvis_camera/capture.py (CameraError, Capture) and worker.py
  (CameraWorker). Frame processing takes and returns a BGR uint8 ndarray.
  Release in finally, send one error, and store at most one unread RGB frame.
- [ ] Add tests/test_camera_ui.py with actual QApplication, a fake capture
  factory, and event-loop waits. Verify navigation, active only after a frame,
  read failure clearing preview, retry, stop and deferred close.
- [ ] Implement jarvis_ui/camera_panel.py, integrate window.py, revise state.py
  and its old tests to show only connected systems as active.
- [ ] Add OpenCV to requirements.txt and document launch, camera controls,
  architecture, driver limitations and manual hardware checks in README.md.
- [ ] Run all tests and syntax checks, render a simulated preview for visual
  inspection. Back up original changed files before copying verified updates
  to the user's project and verify deployed file hashes.
